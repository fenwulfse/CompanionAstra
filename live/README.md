# Claudette Live AI Drafts

These files are research artifacts only. They are not an installable mod and
must not be copied into Fallout 4 `Data`.

`claudette_character_override_draft.csv` follows the Mantella v0.14 character
override column layout as inspected on 2026-07-18. The row is deliberately not
voice-configured. Plugin-local FormIDs, load-order handling, persona text, and a
licensed TTS voice all require validation in an isolated profile before import.

The standalone `CompanionClaude.esp` remains the authoritative companion and
must never depend on this track.
