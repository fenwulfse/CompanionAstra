## Nexus Description

Astra is a new Fallout 4 companion project currently in alpha.

This build focuses on getting Astra working as a real companion: she can be recruited, dismissed, commanded, travel with the player, gain affinity through normal gameplay, and trigger at least the early affinity scene naturally. She also has voiced dialogue files and some random companion comments during exploration.

This is not a finished Bethesda-style companion yet. It is being shared as an early playable build for testers and curious players who want to follow the project while it grows.

### Current Features

- Recruitable Astra companion
- Companion command-wheel support
- Dismiss and pickup support
- Affinity gain through normal play
- Positive affinity from useful actions like workbench use, weapon modding, and armor modding
- Early affinity scene support
- Relationship and thoughts dialogue
- Some random exploration comments
- Existing-save support that attempts to skip the early Red Rocket/Concord route if the player is already beyond it
- Inventory hotfix disables Astra's unconfigured vanilla companion gift-item timer
- Voice files included

### Known Issues

- Alpha-quality and unfinished
- Some voice files may be silent, missing, or mapped to the wrong line
- Combat responses are likely incomplete or missing
- Random comments may fire in odd contexts
- Dialogue polish is still early
- Quest content is experimental and not the current focus
- Existing saves that previously had Astra installed may behave differently than a clean save
- Existing saves that already contain bad inventory stacks may still need a one-time console cleanup

### Suggested Test Setup

For the cleanest test, use a save that has never had Astra installed.

If you are testing changes on a save that previously had Astra active, disable the plugin, load and save without it, exit the game, re-enable the plugin, then load that clean intermediate save.

### Installation

Install like a normal loose-file Fallout 4 mod:

1. Copy the contents of the included `Data` folder into your Fallout 4 `Data` folder.
2. Enable `MQAstraALT.esp`.
3. Load a clean save or start a new game.
